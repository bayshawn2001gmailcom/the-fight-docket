# Fight Night Watchdog — Outcome Rubric

Grade each run as PASS only if ALL criteria are satisfied.

1. **Event check completed** — Agent searched for tonight's combat sports events and either posted results OR wrote a clear "no events tonight" explanation to summary.md. Not just a blank output.

2. **Facts are accurate** — Every posted result has correct winner, method (KO/TKO/UD/SD/MD/RTD/DQ/NC), round number, and time. Verified against ESPN, MMA Fighting, UFC.com, or BoxingScene — not just one social media post.

3. **No duplicates** — Memory store was checked before posting. No result appears twice in /mnt/memory/posted_results.md for the same event.

4. **All 3 platforms attempted** — For each result, Instagram, Facebook, and Twitter/X were all attempted. If one fails, the others still go through. Summary.md records the status of each platform per result.
