Task 1 — Monday: Post Newsletter Preview Card
Instagram + Facebook — Preview Card MONDAY AFTERNOON (after 11am EDT)

GitHub Actions generates the graphics at 11am EDT. Wait until then, then post.

1
Open the IG folder to get the image file:
C:\Users\baysh\Fight Newsletter\.tmp\ig\
Look for the file ending in _newsletter_preview.png
Example: jun16_2026_newsletter_preview.png
2
Open the captions file for the caption text:
C:\Users\baysh\Fight Newsletter\.tmp\ig\MONTHDD_YYYY_captions.txt
Example: jun16_2026_captions.txt — find the "Preview" section and copy that caption
3
Post by running this command in the terminal: cd "C:\Users\baysh\Fight Newsletter" python tools/social_post.py --card=preview --platform=all Posts to Instagram AND Facebook automatically. If it fails, post manually from the files above.
Task 2 — Monday: Run SEO Article + Publish
Generate & Publish Weekly SEO Article MONDAY (after newsletter pipeline runs)

This creates a public article on Beehiiv that Google can find and index. No Firecrawl credits used — it reads the newsletter draft already saved on the computer.

1
Run the SEO article generator: cd "C:\Users\baysh\Fight Newsletter" python tools/seo_article.py It will print a Beehiiv draft link when done. Copy that link.
2
Open the Beehiiv draft link (printed in the terminal)
It looks like: https://app.beehiiv.com/posts/post_xxxxxxxx
3
In Beehiiv: Click "Publish" → choose "Web only"
This makes the article public on the web WITHOUT emailing your subscribers.
Your subscribers already get the full newsletter — this article is for people finding you on Google.
4
Article is also saved locally:
C:\Users\baysh\Fight Newsletter\.tmp\seo_articles\

Fight Night Protocol — Post Results Immediately
Post a Fight Result RIGHT After It Happens FRIDAY OR SATURDAY NIGHT — DURING THE EVENT

GitHub Actions auto-posts live results every 90 min, but if you want something posted INSTANTLY (main event, big upset), run this manually as soon as the fight ends.

1
Open a terminal (Git Bash or PowerShell) and run: cd "C:\Users\baysh\Fight Newsletter" python tools/post_result_now.py --winner="WINNER NAME" --loser="LOSER NAME" --method="KO/TKO" --round=3 --time="2:45" --event="UFC 315"
2
Fill in the actual fight details. Method options:
KO/TKO  ·  Submission  ·  Decision (Unanimous)  ·  Decision (Split)
3
Example — Gaethje TKO win: python tools/post_result_now.py --winner="Gaethje" --loser="Topuria" --method="KO/TKO" --round=4 --time="4:51" --event="UFC Freedom 250"

Task Scheduler — Runs Automatically (PC Must Be ON)
Task NameRunsWhat It Does
TokenRefresh Monday 7:30am EDT Refreshes Instagram/Facebook access tokens (keeps posting working)
PostAnnouncement Thursday 9:00am EDT Posts the fight announcement card to Instagram + Facebook
PostQuote Saturday 10:00am EDT Posts the weekly quote card to Instagram + Facebook

If the PC is asleep or off when these run, the task will be missed. Wake the PC before these times if you know it will be off.
To check task history: Task Scheduler → Task Scheduler Library → FightDocket → right-click task → History.

If Something Goes Wrong
ProblemFix
social_post.py fails — token expired Run: python tools/refresh_tokens.py then retry
No files in .tmp/ig/ after Monday 11am Check GitHub Actions: github.com/bayshawn2001gmailcom/the-fight-docket/actions
seo_article.py can't find a draft Newsletter pipeline didn't run — check GitHub Actions or run newsletter_draft.py manually
Post went to wrong account / duplicate post Check Instagram app and Facebook Page manually to delete. Then re-run with correct card.
GitHub Actions shows red X Go to the Actions tab, click the failed run, read the error. Usually a missing API credit or token issue.
